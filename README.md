# 애니 자막 찾기

키워드로 애니시아의 작품 목록을 찾고, 작품을 선택해 공개 자막 파일을 검색하는 Windows용 Python 앱이다. 제목을 이미 안다면 목록 선택 없이 바로 자막을 검색할 수도 있다. 한국어 자막은 **애니시아에 등록된 제작자 블로그 → Google의 공개 블로그 검색** 순서로 찾는다. OpenSubtitles는 자동 호출하지 않으며, `OpenSubtitles에서도 검색` 버튼으로 직접 추가 검색할 수 있다.

## 실행

1. Windows에 Python을 설치하고 설치할 때 `py` 실행기를 활성화한다. 현재 초안은 Python 3.10 이상과 기본 포함된 Tkinter만 사용한다.
2. ZIP을 한 폴더에 풀고 `run_windows.bat`을 실행한다. `python run.py`도 가능하다.
3. `애니 제목`에 `이세계`처럼 키워드를 입력하고 `작품 찾기`를 누른다. `검색된 작품` 목록에서 원하는 작품을 선택한다. 시즌과 화수는 선택 사항이다. **화수를 비워 두면 확인된 회차별 후보를 함께 보여 주고, 화수를 입력하면 해당 회차를 우선 찾는다.** `선택 작품 자막 검색`을 누르거나 작품을 더블클릭한다. 애니시아가 최신화 링크만 제공한다면 `선택 작품 원본 블로그 열기`로 제작자의 블로그 홈을 열 수 있다.
4. `자막 후보` 목록에서 파일을 더블클릭하거나 선택한 뒤 `선택 자막 다운로드`를 누른다. 우클릭 메뉴에서도 다운로드·원문 열기를 선택할 수 있다. 성공하면 저장 경로가, 실패하면 원인이 팝업으로 표시된다.

정확한 제목을 알고 있거나 애니시아 목록에서 작품을 찾지 못했다면 `입력 제목으로 자막 검색`을 누를 수 있다. 이 경로는 입력한 제목으로 자막 출처를 직접 찾으며, 애니시아 작품 목록을 먼저 보여 주지 않는다. 한국어 외 언어를 선택하면 `작품 찾기`도 OpenSubtitles 자막 검색으로 이어지므로 API 키가 필요하다.

검색 중 `취소`를 누르면 화면 대기를 종료한다. 이미 시작한 HTTPS 요청은 타임아웃까지 백그라운드에서 진행될 수 있다.

`subtitles/<작품명>/Season 01/`에 저장한다. 시즌을 입력하지 않으면 `Unsorted/`에 저장한다. 같은 이름이 이미 있으면 `(2)`처럼 번호를 붙인다. 각 파일 옆의 `.source.json`에 다운로드 출처를 기록한다.

작품명만 입력하면 전체 시즌이 검색될 수 있다. 목록의 시즌·화수·제작자를 보고 파일을 골라야 한다. 확실하지 않은 압축파일은 원본 그대로 저장한다. ZIP은 자막이 단일 파일로 특정되면 안에서 꺼낸다. 7z/RAR은 Windows에 7-Zip이 설치돼 있으면 단일 자막 추출을 시도하고, 그렇지 않으면 원본 압축파일을 저장한다.

## 출처와 작동 순서

- `작품 찾기`는 `api.anissia.net/anime/list/{page}?q=...`의 작품 목록을 가져온다. 여기서 나온 작품은 **자막 후보가 아니라 애니 제목**이다. 작품을 선택하면 해당 `animeNo`의 `/anime/caption/animeNo/{id}`에서 제작자 블로그를 확인하고 네이버·티스토리·Blogger의 공개 첨부를 검색한다. 애니시아가 최신화 한 건만 알려 주어도, 등록된 블로그의 공개 검색·피드에서 이전 회차를 찾는다. 네이버 첨부 서버, Kakao CDN, Google Drive 링크에서 파일을 받는다.
- `입력 제목으로 자막 검색`과 명령줄 검색은 입력 제목으로 애니시아 작품을 추정해 자막을 찾는 기존 경로다. 영문/일문명만 입력하면 AniList와 Wikidata에서 제목 별칭을 확인한다. 짧거나 넓은 키워드는 작품 추정에 실패할 수 있으므로 GUI에서는 먼저 `작품 찾기`로 작품을 선택하는 편이 좋다.
- 위 경로에 결과가 없으면 앱이 Python HTTPS 요청으로 Google의 `작품명 [화수] 자막` 검색 결과를 확인하고 지원 블로그 글을 검사한다. Google이 자동 검색을 제한하면 검색 실패와 해당 검색 URL, `Google 검색 열기`·`URL 복사` 버튼을 표시한다. 브라우저에서 찾은 게시글 주소를 앱의 링크 입력칸에 붙여넣고 `이 링크에서 찾기`를 누른다.
- ReAnime와 같이 등록 제작자의 글에서 요청한 화수를 확인하고, 일치하는 첨부를 고른다. 화수를 비워 검색할 때는 Blogger 피드와 네이버·티스토리 검색 페이지에서 여러 회차를 모은다. 검색 제목의 `[자막]` 표기, 시즌 표기, 티스토리 검색 카드의 제목 속성, 압축 파일 안의 회차별 파일명을 확인한다. 티스토리가 시즌별 화수 대신 통산 화수를 쓸 때는 애니시아 최신 화수와 제작자 최신 글로 번호 차이를 확인한 경우에만 `검토` 후보로 제시한다. 정확한 후보가 없으면 Google 공개 검색도 확인한다. 제작자 사이트나 검색 페이지가 오류를 반환하면 자막 부재로 확정하지 않고 오류를 표시한다.
- OpenSubtitles REST API는 `OpenSubtitles에서도 검색` 버튼을 눌렀을 때만 추가로 검색한다.
- Bigfile의 공개 자막 목록은 `Bigfile 애니 검색 (영문명)` 버튼으로 별도 검색한다. 버튼을 누르면 영문 작품명을 입력하는 창이 열리고, 앱이 `애니` 분류의 결과를 검색해 파일명과 회차를 보여 준다. Bigfile 파일 다운로드에는 사이트 로그인이 필요하다. 후보를 선택하고 `선택 원문 열기` 또는 `선택 자막 다운로드`를 누른 뒤 사이트에서 `애니`를 선택하고 같은 영문 제목으로 검색하여 로그인 후 받는다.
- 다른 언어를 선택하면 OpenSubtitles로 바로 검색한다. ReAnime 쪽은 한국어 자막 제작자 출처 중심이다.

OpenSubtitles 검색에는 본인 API 키가 필요하다. 앱의 `API 키 발급 방법` 버튼을 누르면 발급 절차와 [공식 API Consumers 페이지](https://www.opensubtitles.com/en/consumers) 링크가 팝업으로 열린다. 발급한 키는 `OpenSubtitles API 키` 버튼에서 저장한다. 저장한 키는 `settings.json`에 로컬로 보관하며 API 요청 헤더에만 사용한다. API 키가 없어도 한국어 ReAnime 검색은 가능하다.

## 명령줄 및 EXE

```bat
py -3 run.py "강철의 연금술사" --season 1 --episode 1
py -3 run.py "Steins;Gate" --open-only --language ko
py -3 run.py "Ascendance of a Bookworm" --bigfile-only --episode 22
py -3 run.py "강철의 연금술사" --season 1 --episode 1 --download 1
```

Windows에서 EXE가 필요해지면 `build_windows.bat`을 실행한다. PyInstaller가 설치되고 `dist/AnimeSubtitleFinder.exe`가 만들어진다. 실행 파일 옆에 `subtitles/`가 만들어진다. 공개 사이트의 검색 동작은 일부 실시간 확인했으며, 사이트 변경과 로그인 상태에 따라 결과가 달라질 수 있다.

구현 범위와 Windows 확인 순서는 [PLAN.md](PLAN.md)를 참고하면 된다. 코드의 모의 응답 테스트는 `py -3 -m unittest discover -s tests -v`로 실행한다.

## 제한과 소스

- 공개 게시글과 공개 파일만 처리한다. 제작자 사이트 구조 변경, Google CAPTCHA, 로그인이 필요한 첨부파일은 결과가 없거나 오류가 날 수 있다.
- `작품 찾기`는 애니시아가 반환한 제목을 기준으로 목록을 만들며 자막 존재 여부를 뜻하지 않는다. 애니시아 검색 결과가 없거나 API 요청이 실패하면 작품 목록이 비어 있을 수 있다. 검색 페이지는 최대 200페이지까지 확인한다.
- HTML/파일 응답은 크기 제한을 두고, 지원 출처의 HTTPS 링크만 자동 다운로드한다. ZIP 내부 파일도 요청 화수에 맞는 자막 하나가 확정될 때만 추출한다.
- 출력 형식은 SRT, SMI/SAMI, VTT, ASS/SSA 또는 ZIP, 7z, RAR이다. 별도 영상 다운로드 기능은 없다.
- 이 코드는 두 확장 프로그램에서 **검색 경로와 아이디어를 참고해 새로 작성한 초안**이다. 원본 확장 코드와 원본 자막 파일을 ZIP에 포함하지 않는다.
